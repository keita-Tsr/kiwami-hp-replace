## 2. 固定コンテンツ

### 2.1 こだわり

現行の紹介文は、以下の趣旨で引き継ぐ。

- お客様に笑顔になってもらうため、日々丁寧に焼いていること
- 国産米粉を100%使用していること
- 外はカリッと、中はもっちりした食感であること
- くず粉でとろみをつけた甘辛たれを使用していること

文章をそのまま利用するか、リニューアルに合わせて編集するかは店舗確認後に決定する。

### 2.2 画像

| 用途 | 現行サイト上の有無 | 確認事項 |
| --- | --- | --- |
| ロゴ | 現行HTMLではGyazoの外部画像を参照 | 元画像の保管場所、利用権限、推奨サイズ |
| メインビジュアル | `Kiwami_img/mainvisual.jpg` | 利用権限、代替テキスト |
| こだわり紹介写真 | `Kiwami_img/こだわり1.jpeg`、`こだわり2.png` | 利用権限、代替テキスト |
| メニュー写真 | `Kiwami_img/` 内に商品ごとの原本あり | 商品との対応、利用権限、代替テキスト |
| 駐車場案内画像 | `Kiwami_img/parking.png` | 掲載継続の要否、代替テキスト |

画像は現行サイトのURLやGyazoなどの外部URLを直接参照せず、確認済みの元データをプロジェクトまたはCMSへ登録して使用する。
