| 項目 | 内容 |
| --- | --- |
| 対象 | kiwamitakoyaki.com リプレイス |
| ステータス | MVP方針確定（詳細仕様は一部要確認） |
| 関連資料 | [技術選定書](./tech-selected.md)、[仕様書](./spec.md) |

## 1. 目的

- 店舗サイトを安全かつ継続的に運用できる状態へリプレイスする。
- 店舗側が必要なコンテンツを更新できるようにする。
- 表示速度と検索エンジンでの評価を改善する。

## 2. 背景・課題

- 現状は、開発者がHTMLを編集してFTPで公開している。
- コンテンツ更新のたびに開発者の作業が必要である。
- サーバー費用と手動公開による作業ミスのリスクがある。

詳細は[技術選定書](./tech-selected.md)を参照する。

## 3. スコープ

### 対象

- 1ページ構成の店舗サイトとしてリプレイス
- コンテンツ管理のCMS化
- ホスティング移行
- SEO・表示速度の改善

### 対象外

- オンライン注文
- 事前予約
- オンライン決済
- 会員機能・ログイン

将来追加の可能性はあるが、今回のリリース対象には含めない。

## 7. 制約・前提

- 現行ドメインは継続利用する。
- 初回リリースはトップページ1ページ構成とする。
- CMSで更新する対象は「新着情報・休業日」「メニュー」「店舗情報・営業時間」の3領域とする。
- ロゴ、こだわり文章、メインビジュアル、基本デザインは固定コンテンツとして実装する。
- 初回リリースでは、現行サイトのデザイン（配色・ページ構成・写真を主体とした見せ方）を踏襲し、デザインの刷新は行わない。レスポンシブ表示やアクセシビリティ上必要な調整は許容する。
- CMS、ホスティング、ソース管理の方針は[技術選定書](./tech-selected.md)に従う。
- メール運用の有無と移行方針は、公開切替前に確認する。
- 未確定事項は実装確定前にレビューで決定する。
